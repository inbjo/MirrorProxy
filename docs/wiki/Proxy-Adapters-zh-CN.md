# 代理适配器

MirrorProxy 支持 GitHub；Docker Hub、GHCR、Quay 和 Kubernetes OCI；Composer、
npm、Go、Maven、RubyGems、NuGet、CPAN、CRAN、Hackage、Julia、LuaRocks、
Clojars、CocoaPods、Pub、Anaconda、PyPI 和 Cargo；Rustup、NVM、Homebrew、
WinGet、TeX Live、ELPA、Nix、Guix 和 Flatpak；以及 `/os` 下白名单内的 Linux、
BSD、OpenWrt、Termux、MSYS2 和 ROS 软件仓库。

`/api/sources` 是 Web 门户使用的权威目录。后台“高级设置”控制适配器开关和上游组；
逗号分隔的多个上游会按顺序尝试。
