# GeoIP 与 IP 访问控制

MirrorProxy 使用离线 ip2region XDB v3 数据库支持 IPv4 和 IPv6。服务端发布包和容器
镜像内置固定版本；后台展示路径、大小、时间与 SHA-256，支持不落库的单 IP 查询，
超级管理员还可以执行原子手动更新。数据库缺失或损坏时地域降级为 `Unknown`，不会
停止代理或 IP 名单。

访问规则支持精确 IPv4/IPv6 和 CIDR。精确地址规范化为 `/32` 或 `/128`，CIDR 自动
规范化到网络地址。黑名单永远优先；一旦存在启用的白名单，未命中的来源默认拒绝。
规则只作用于已识别的代理路径，因此不会把后台和健康检查锁死。

地域报表按日期、代理目标、国家、省和城市聚合已完成的响应，并分别展示实际下发与
计费字节。系统不保存原始客户端 IP 和临时查询结果；更新数据库不会改写历史聚合。
