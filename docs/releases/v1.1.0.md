# MirrorProxy 1.1.0

这是一次覆盖服务端、Web 控制台、独立客户端、部署链路和 CI 的大版本更新。核心变化是把
MirrorProxy 从单一公共代理服务扩展为具备逐地址健康检测、用户身份、分层配额、专属子域名
和完整可观测能力的自托管镜像平台。

## 重点更新

### 镜像源健康检测与故障切换

- 服务启动后自动检测所有已启用代理目标，此后每 15 分钟执行一次完整检测。
- 逗号分隔的多个上游地址逐个独立检测；单个地址失败会单独标记，目标整体显示为
  `degraded`，不会被健康备用地址掩盖。
- 公开页面显示脱敏后的镜像状态，管理后台显示地址级错误详情并支持立即重新检测。
- 检测结果写入 SQLite，重启后公开页面和后台仍使用同一份最近状态。
- OCI Registry 返回带 Bearer challenge 的 `401` 时按正常鉴权握手处理。
- 实际代理请求除非 200 外，还会在连接失败、DNS 错误和超时时按配置顺序切换备用地址。
- Maven、Fedora、Kali 默认上游调整为本轮已验证可用的备用地址：
  - `https://maven-central.storage-download.googleapis.com/maven2`
  - `https://mirrors.xmission.com/fedora/linux`
  - `https://kali.download/kali`

### 用户、登录与管理员体系

- 新增独立用户门户、邮箱验证码和 Magic Link 无密码登录、SMTP 邀请以及持久化重试 Outbox。
- 新增 OAuth2/OpenID Connect 登录，支持 PKCE、state、nonce、已验证邮箱策略、身份绑定与解绑，
  并提供 GitHub、GitLab、Gitee、Google、Microsoft、Keycloak、Authentik 等模板。
- 新增多管理员账号、`admin`/`super_admin` 角色、会话管理、密码找回、审计记录和最后一个
  超级管理员保护。
- 新增可选 WebAuthn Passkey 认证以及应急管理员恢复流程。
- 管理控制台切换到 Cookie 会话和 `/admin/api/*`；旧 Bearer API 暂时保留用于迁移兼容。

### 专属子域名与分层配额

- 每个用户可分配不暴露数据库 ID 的 Sqids 专属子域名，并支持冷却期后自助更换。
- 新增通配符 DNS/TLS 就绪校验、可信反向代理 Host 解析和控制入口隔离。
- 支持全局、计费组、用户三级月度配额，以及并发请求下的原子容量预留和准确流量归属。
- 支持用户默认配额、独立覆盖、无限配额、组成员管理和双向流量计费。

### 安全、代理与可观测性

- 新增全局 HTTP/HTTPS/SOCKS5/SOCKS5H 出站代理、`no_proxy` 以及凭据保护。
- 支持为精确匹配的上游主机配置静态 Basic/Bearer 凭据，并可选择转发客户端 Token。
- 强化登录限流、锁定、会话撤销、密钥脱敏和可信反向代理边界。
- 新增 Prometheus 指标、OpenTelemetry 导出、结构化请求追踪、诊断明细保留策略与示例告警。
- 扩展 Maven 优先级聚合、跨生态代理兼容性，以及 Linux/macOS/Windows 原生改源和精确回滚。

### Web、部署与发布工程

- 将前端构建链的 PostCSS 升级到 8.5.23，修复高危 source map 路径穿越漏洞
  GHSA-r28c-9q8g-f849；npm 官方审计结果为 0 个漏洞。
- 重构内嵌 React 控制台，增加镜像健康、用户、管理员、邮件、身份提供方、配额、安全和
  可观测性管理界面。
- 简化 Docker Compose 配置，补充 Nginx、Caddy、Traefik、Apache、HAProxy 的通配符
  域名部署示例。
- Docker Hub 发布增加多架构签名、SBOM 和 provenance attestations。
- 扩充 Rust 单元测试、Vitest、Playwright E2E、真实客户端协议 smoke 和三平台原生客户端测试。

## 升级说明

1. 升级生产环境前备份 SQLite 数据库与 TOML 配置。
2. 1.1.0 首次启动会自动执行向前兼容的数据库迁移；不要使用旧版二进制回滚已迁移的数据库。
3. 现有公共代理路径默认保持可用。用户子域名是可选功能；启用 `subdomain_required` 前必须
   配置通配符 DNS、TLS、原始 Host 转发和可信代理，并显式确认基础设施就绪。
4. 环境变量仍优先于 TOML 和数据库运行时设置。升级后建议在管理后台逐项检查新增配置。
5. 已显式配置的 Maven、Fedora、Kali 地址不会被自动覆盖；如需使用本次验证过的默认值，
   请手动更新对应上游。

完整英文变更记录见 [CHANGELOG.md](https://github.com/inbjo/MirrorProxy/blob/v1.1.0/CHANGELOG.md)。

## 下载与校验

Release 附件包含 Windows、macOS、Linux 独立客户端和 Linux 服务端压缩包、逐文件 `.sha256`
以及汇总 `SHA256SUMS`。安装脚本会自动选择平台并校验 SHA-256：

```bash
curl -fsSL https://raw.githubusercontent.com/inbjo/MirrorProxy/main/scripts/install.sh | sh
```

Docker 镜像：

```bash
docker pull kudang/mirrorproxy:1.1.0
```
